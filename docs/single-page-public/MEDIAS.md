# Médias des zones

## Parcours livré

Images déjà publiques et approuvées :
- Vitesse : assets/render-speed.jpg
- Agilité : assets/render-agility.jpg
- Mains : assets/render-hand.jpg
- Pieds : assets/render-foot.jpg
- Game IQ : assets/render-iq.jpg
- Terrain distinct : assets/school-home/arene-avec-reperes.webp

Les cinq premiers fichiers sont 900×720. Le cadre utilise object-fit:contain pour montrer toute l’image, sans déformer ni couper les personnes. Les titres et descriptions sont des éléments HTML traduisibles. Les inscriptions déjà présentes dans les illustrations sont inchangées.

## Extraits retrouvés mais non exposés

Les fichiers zone-speed.mp4 (~2,7 Mo), zone-agility.mp4 (~2,7 Mo), zone-hand.mp4 (~2,5 Mo), zone-foot.mp4 (~3,3 Mo), zone-iq.mp4 (~3,8 Mo) existent à la racine. concept.html les référence déjà comme médias correspondants. Leur contenu visuel et audio n’a pas été validé pour cette nouvelle présentation. Les routes ne figurent pas dans les ressources publiques et sont donc soumises au contrôle de connexion existant.

Aucune protection n’est modifiée pour cette mission. Aucun téléchargement ou découpage de YouTube, timecode supposé ou faux extrait n’a été créé. La vidéo générale conserve son emplacement distinct.

## Activation ultérieure

Chaque article .zone-detail possède data-zone-video="". Après validation du fichier complet et de son accès public autorisé, renseigner ce champ avec l’URL de l’extrait spécifique. Ne pas utiliser le trailer général ni une route protégée.

Le code optionnel existant affiche alors « Lire l’extrait », crée un unique lecteur HTML vidéo uniquement sur activation, avec commandes natives, playsinline, sans son automatique ni chargement préalable des cinq fichiers. Le changement de zone, la fermeture et la sortie de page arrêtent et retirent le lecteur. Un échec de chargement restaure l’image et affiche le message bilingue. Ce chemin optionnel est couvert par un test simulé ; aucun de ces lecteurs n’est affiché dans l’aperçu livré.

À fournir/confirmer : cinq extraits validés, ou sources autorisées et points d’entrée/sortie précis. Pour réutiliser les cinq fichiers existants, confirmer leur contenu, leur audio et l’autorisation de leurs URL publiques dans une tâche ultérieure.
