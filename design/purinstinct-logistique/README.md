# Kit de section PürInstinct

1. Décompresser ce ZIP dans `design/purinstinct-logistique/` du dépôt.
2. Copier le contenu de PROMPT_CODEX.txt dans Codex.
3. Joindre si possible reference/maquette-validee.png au chat pour sa lecture visuelle.

## Contenu
- reference/maquette-validee.png : référence approuvée avec terrain gazonné.
- assets/panorama-sans-texte.png : photographie de fond reconstruite sans textes.
- content.fr-en.json : copie exacte FR et traduction EN.
- SPECIFICATIONS.md : consignes de mise en page et de vérification.
- PROMPT_CODEX.txt : instruction complète d’exécution.

Le kit ne contient pas le code actuel du site et aucun audit du dépôt n’a été réalisé pour sa préparation. Codex doit adapter l’implémentation aux composants et fontes déjà présents. Aucune police commerciale n’est redistribuée.
